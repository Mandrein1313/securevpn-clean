# SecureVPN Full (เว็บ + หลังบ้าน เฟสเว็บ)

โปรเจกต์เว็บเช่า/ให้บริการ VPN แบบครบหน้าสำหรับเริ่มธุรกิจอย่างระมัดระวังตามกรอบกฎหมายไทย

## ไฟล์หลัก

| ไฟล์ | คำอธิบาย |
|------|-----------|
| `index.html` | หน้าลูกค้า + ฟอร์มสั่งซื้อ (ต้องยอมรับ TOS) |
| `tos.html` | ข้อตกลงการใช้งาน (รวมหน้าที่เก็บ Log) |
| `privacy.html` | นโยบายความเป็นส่วนตัว |
| `aup.html` | นโยบายการใช้ที่ยอมรับได้ / ข้อห้าม |
| `admin.html` | หลังบ้าน: ออเดอร์, Connection Log, Abuse |
| `js/store.js` | คลังข้อมูล localStorage |
| `js/main.js` / `js/admin.js` | โลจิกหน้าบ้าน/หลังบ้าน |

## สิ่งที่ครอบคลุมจากแนวทางปฏิบัติ

1. **เปิดเผยการเก็บ Log** บนหน้าเว็บและ TOS (IP ลูกค้า, บัญชี, เวลา, server IP/port) ≥ 90 วัน  
2. **TOS / Privacy / AUP** ให้ลูกค้ายอมรับก่อนสั่งซื้อ  
3. **หลังบ้านออเดอร์** เปลี่ยนสถานะ ใส่บัญชี VPN ระงับบัญชี  
4. **Connection Log UI** สำหรับบันทึก/ค้นหา (บนระบบจริงต้องดึงจาก VPN server)  
5. **Abuse workflow** บันทึกเรื่อง ผูกบัญชี ติดตามสถานะ  
6. แนะนำชำระเงินที่ตรวจสอบได้ และความร่วมมือเมื่อมีหนังสือราชการ  

## สิ่งที่ไฟล์นี้ยังไม่ทำแทนคุณ

- การตั้ง Firewall / บล็อกพอร์ตบนเซิร์ฟเวอร์ VPN จริง  
- การเก็บ Log อัตโนมัติจาก WireGuard/OpenVPN  
- เกตเวย์ชำระเงินอัตโนมัติ  
- การให้คำปรึกษากฎหมายรายกรณี (เอกสาร TOS เป็นตัวอย่าง ควรให้ผู้เชี่ยวชาญตรวจ)

## ติดตั้งบนมือถือ (Nexus Studio)

1. แตก zip ไป `/sdcard/MiniStudio/SecureVPN/`  
2. เปิด `index.html` แล้ว Preview  
3. หลังบ้าน: เปิด `admin.html` รหัสเริ่มต้น `1234`  
4. เปลี่ยน `ADMIN_PIN` ใน `js/store.js`  
5. Push GitHub → เปิด Pages  

ลิงก์ตัวอย่าง:

- ลูกค้า: `https://<user>.github.io/<repo>/`  
- แอดมิน: `https://<user>.github.io/<repo>/admin.html`

## ข้อจำกัด localStorage

ข้อมูลอยู่บนเบราว์เซอร์เครื่องนั้น ลูกค้ากับแอดมินคนละเครื่องจะไม่เห็นข้อมูลชุดเดียวกันจนกว่าจะย้าย Store ไป Supabase/เซิร์ฟเวอร์

## ขั้นตอนถัดไปที่แนะนำ

1. ย้าย `store.js` ไป Supabase  
2. รับ webhook/log จาก VPN node  
3. เชื่อม PromptPay / สลิป  
4. ให้ทนายตรวจ TOS–Privacy–AUP ก่อนเปิดบริการจริง
